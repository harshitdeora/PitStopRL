A WINDOW INTO THE AGENT

Race state in.
Strategy out.

This preview runs the project's trained Double DQN weights directly in your browser. No server, account or internet connection is needed after loading.

01Observe

The simulator supplies 27 features: distance remaining, tyre wear, fuel, safety-car status and the race settings.

02Evaluate

Two hidden layers of 128 neurons produce four Q-values. Brighter neurons have larger activations; visible connections are a subset of the actual learned weights.

03Act

The agent chooses the highest Q-value. The next lap changes the state, and the process repeats. Its weights stay fixed throughout playback.

The car animation illustrates a lap-based strategy simulator. It does not model steering, overtaking or vehicle physics. Browser races use a deterministic browser RNG; the Python CLI uses NumPy's RNG, so an identical seed does not produce an identical race across the two implementations. The simulator equations and trained weights are the same.
